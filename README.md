# MR Control Curves Automater

### Description
The Maya Rig Control Curves Automater is an autorigging tool which stores control curves on a user's computer and allows them to quickly place them on character rigs. 
Control curves and their groups are named after the joint they constrain and have suffix presets for the user to choose from. 
Size, line thickness, and rotation can also be customized. 
These controls are organized into a "master" and a "controls" group, whose names can be customized. 
Joint constraints are created unless disabled. 


The control curves are created using point data available for free through Zeynep Fisher's Gumroad.
